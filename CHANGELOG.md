# What's new in Veridian E-invoicing Pakistan

Each section is the "What's new" note that installed copies show when they are
offered the update (the release workflow reads the section of its version).

## 1.2.0

- Software updates in one click: Settings → System → Software updates shows each new version and what it brings. Click Update now (the database is backed up first and the software restarts by itself), or let updates install automatically at night.
- The complete Pakistan Customs Tariff 2026-27 is built in: all 7,823 HS (PCT) codes with their descriptions and headings, searchable by code or by words. Invoices warn about a code that is not in the tariff or on FBR's list before they reach FBR.
- FBR's reference lists (HS codes, units, sale types, rates and SROs) are downloaded again automatically every day.
- Users can now be deleted (Settings → Users & roles). Their invoices and audit trail are kept, and the licence seat is freed.

## 1.1.0

- New design for desktop, web and mobile.
- Import customers, products and invoices from any Excel, CSV or PDF file, with column matching and prompts for missing data.
- PDF exports of invoices, reports and a monthly report pack.
- Windows installer with a background service and a desktop app.
